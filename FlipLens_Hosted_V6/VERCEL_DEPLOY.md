# Fastest deployment

## Option A — Vercel + GitHub

1. Go to GitHub and create a repository named `fliplens`.
2. Upload all project files from this ZIP.
3. Open Vercel and create a new Project from that GitHub repository.
4. In the project's Environment Variables add:
   - Name: `RENTCAST_API_KEY`
   - Value: your RentCast API key
5. Deploy.

## Option B — Vercel plugin in ChatGPT

If you connect the Vercel plugin to ChatGPT, ChatGPT may be able to help move deployment steps into the app flow depending on the available permissions.
